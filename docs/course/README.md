# 📚 CodeGol - Documentación del Curso

## 🎯 Visión General

**CodeGol** enseña programación Python a través del fútbol, creando una experiencia de aprendizaje adictiva y efectiva para niños de 8-14 años en contextos de recursos limitados.

## 🌟 Principios Fundamentales

### 1. **Resultados Inmediatos**
Cada sesión produce algo tangible:
- Sesión 1: Crea fichas de jugadores
- Sesión 2: Juego interactivo funcionando
- Sesión 6: Simulador de partidos completo

**Por qué funciona**: Los niños necesitan ver el impacto de su código *ahora*, no "eventualmente".

### 2. **Offline-First**
Todo funciona sin internet confiable:
- Dataset completo incluido (1000+ jugadores)
- APIs con fallback local
- Materiales descargables

**Por qué importa**: Internet intermitente no puede ser barrera de aprendizaje.

### 3. **Progresión Pedagógica**
Basada en la **Taxonomía de Bloom** adaptada:

```
Semanas 1-3:  RECORDAR + ENTENDER    → Variables, print, input
Semanas 4-6:  APLICAR + ANALIZAR     → Funciones, listas, lógica
Semanas 7-9:  EVALUAR + CREAR        → APIs, proyectos propios
Semanas 10-12: CREAR (AVANZADO)      → Proyectos personalizados
```

### 4. **Gamificación Intrínseca**
No solo "puntos por hacer tareas":
- El código mismo es el juego
- Cada función nueva desbloquea capacidades
- Competencia sana: "¿Quién simula mejor?"

### 5. **Escalabilidad desde el Diseño**
Cada elemento se diseña para reutilización:
- Lecciones modulares
- Estructura de datos consistente
- Patrones repetibles

## 📊 Estructura del Curso

### **24 Sesiones | 12 Semanas | 60 min/sesión**

#### **FASE 1: Los Primeros Goles** (Semanas 1-3)
**Objetivo**: Confianza con sintaxis básica

| Semana | Sesiones | Conceptos | Proyecto Visible |
|--------|----------|-----------|------------------|
| 1 | 1-2 | Variables, print, input, strings | "Generador de Fichas de Jugadores" |
| 2 | 3-4 | Condicionales (if/elif/else) | "Predictor de Resultados" |
| 3 | 5-6 | Loops (for/while), range | "Simulador de Tabla de Posiciones" |

**Hito**: Pueden crear un juego simple de predicciones funcionando.

#### **FASE 2: Construyendo Estadios** (Semanas 4-6)
**Objetivo**: Estructuras de datos y reutilización

| Semana | Sesiones | Conceptos | Proyecto Visible |
|--------|----------|-----------|------------------|
| 4 | 7-8 | Listas, append, random | "Generador Aleatorio de Equipos" |
| 5 | 9-10 | Funciones, parámetros, return | "Calculadora de Estadísticas FIFA" |
| 6 | 11-12 | Diccionarios, estructuras complejas | "Base de Datos Personal de Jugadores" |

**Hito**: Tienen una librería reutilizable de funciones de fútbol.

#### **FASE 3: La Liga Digital** (Semanas 7-9)
**Objetivo**: Conectar con datos reales

| Semana | Sesiones | Conceptos | Proyecto Visible |
|--------|----------|-----------|------------------|
| 7 | 13-14 | APIs, requests, JSON básico | "Consultor de Equipos Reales" |
| 8 | 15-16 | Navegación JSON, filtros | "Buscador Avanzado de Jugadores" |
| 9 | 17-18 | Caché, manejo errores, offline | "App Híbrida (online + offline)" |

**Hito**: App que funciona con y sin internet.

#### **FASE 4: Copa Mundial del Código** (Semanas 10-12)
**Objetivo**: Proyectos personalizados

| Semana | Sesiones | Conceptos | Proyecto Visible |
|--------|----------|-----------|------------------|
| 10 | 19-20 | Archivos (read/write), persistencia | "Sistema de Guardado de Partidos" |
| 11 | 21-22 | Proyecto final integrador | "Mi Trivia/Juego Personalizado" |
| 12 | 23-24 | Presentaciones, pulido | "Demo Day" con certificación |

**Hito**: Cada estudiante presenta su juego único.

## 🎮 Metodología de Sesión (60 min)

### Estructura Fija (Crea Hábito):

```
⏰ 0-10 min:  🔥 WARM-UP
   - Trivia rápida (3 preguntas código anterior)
   - Revisión rápida de "tarea opcional"
   - Activar conocimiento previo

⏰ 10-25 min: 📚 CONCEPTO NUEVO
   - Demo en vivo del instructor (7 min)
   - Explicación con analogía de fútbol (3 min)
   - Primer ejemplo guiado juntos (5 min)

⏰ 25-50 min: 💻 PRÁCTICA ACTIVA
   - Ejercicio guiado (10 min)
   - Ejercicio semi-independiente (10 min)
   - Desafío creativo (5 min)
   - Instructor circula ayudando

⏰ 50-60 min: 🏆 SHOW & TELL
   - 2-3 niños muestran su código (5 min)
   - Recap de conceptos clave (3 min)
   - Preview emocionante próxima clase (2 min)
```

### Principios Pedagógicos:

1. **I Do, We Do, You Do**
   - Instructor demuestra
   - Hacen juntos
   - Practican solos

2. **Error como Aprendizaje**
   - Celebrar bugs: "¡Encontraste un error interesante!"
   - Debugging como detective
   - Errores comunes se convierten en lecciones

3. **Diferenciación Natural**
   - Ejercicios básicos (todos)
   - Desafíos extra (avanzados)
   - Ayuda entre pares (todos aprenden)

## 📐 Sistema de Evaluación

### No hay "exámenes" tradicionales

En su lugar:
- ✅ **Portfolio de Proyectos**: Cada sesión añade al portafolio
- ✅ **Auto-evaluación**: "¿Puedes explicar esto a un compañero?"
- ✅ **Badges de Logro**: "Primera función", "API Master", etc.
- ✅ **Proyecto Final**: Demuestra todos los conceptos

### Rúbrica Simple (4 niveles):

| Nivel | Descripción | Ejemplo |
|-------|-------------|---------|
| 🌱 Explorando | Necesita ayuda constante | Copia código sin entender |
| 🌿 Desarrollando | Completa con guía ocasional | Modifica ejemplos básicamente |
| 🌳 Competente | Trabaja independiente | Crea variaciones propias |
| 🚀 Experto | Enseña a otros, innova | Agrega features no pedidas |

## 🌍 Consideraciones Culturales

**América Latina**:
- Ejemplos: Messi, equipos CONMEBOL
- Rivalidades locales (Boca-River, etc.)
- Copa Libertadores, Copa América

- J-League, K-League
